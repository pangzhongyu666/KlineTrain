# KlineTrain

**全品类训练模式**
股票双盲训练（隐藏名称与日期）
涨停专项训练
指数训练（上证/深证/创业板等）
ETF训练（宽基与行业）
**专业交易模拟**
分仓操作，模拟真实持仓管理
多空双向交易
杠杆设置，适配期货等品种
训练时段与市场风格自由定制
真实历史行情回放，零资金风险
**看盘与分析工具**
真实历史数据
全周期切换：分时、5/15/30/60分钟、日周月K线
筹码分布分析
十余种技术指标可任意叠加（MACD/EMA/BOLL/KDJ/ATR/RSI/CCI 等）
自定义公式指标：自由编写指标公式，快速验证交易模式，打造专属交易系统
**战法复盘与成长**
战法复盘系统：打造专属战法，用战法制定交易计划
按计划交易，交易记录自动归入对应战法
分战法统计：每个战法的胜率、盈亏比一目了然
复盘笔记：记录复盘心得，持续沉淀交易体系
智能复盘，自动分析每笔交易盈亏原因
数据统计报表：胜率、盈亏比、成长曲线
